# Armor

Armor library for the Fey Glade scene. Characters reference armor by `id` in CONFIG.md.
`ac_dex_cap: none` means DEX modifier is uncapped (light armor).

| id | name | ac_base | ac_dex_cap | stealth_disadvantage |
|----|------|---------|------------|----------------------|
| plate_armor | Plate Armor | 18 | 0 | true |
| chain_mail | Chain Mail | 16 | 0 | true |
| studded_leather | Studded Leather | 12 | none | false |
| leather_armor | Leather Armor | 11 | none | false |
| draconic_resilience | Draconic Resilience | 13 | none | false |
| no_armor | No Armor | 10 | none | false |
| natural_armor_shadowbeast | Natural Armor | 11 | none | false |
